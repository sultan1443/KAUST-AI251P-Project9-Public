# M4 and M5 — Source Review

This folder is for the sanitized M4 object detection and M5 instance segmentation source code and experiment evidence.

Status: Under review. Full reproducibility has not yet been independently verified.

Dataset images, model weights, passwords, and private files are not included.

The original frozen Test evaluation must not be rerun.
